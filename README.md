# Pacific Rim Mod для Minecraft 1.21.x

Полноценный мод по фильму **"Тихоокеанский рубеж"** (Pacific Rim) с всеми механиками до микрочастиц!

## 🎬 Особенности мода

### 🤖 Егери (Jaegers)
- **Gipsy Danger** (Mark-3) - основной Егерь фильма
  - Ядерный режим активации
  - Система Дрейфа с совместимостью пилотов
- **Cherno Alpha** (Mark-1) - российский тяжелый танк
  - Молниевые пушки
  - Высокая броня

### 🦖 Кайдзю (Kaiju)
- **Leatherback** (Категория 4) - ЭМИ монстр
  - Электромагнитные импульсы
  - Разрушение техники
- **Otachi** (Категория 4) - летающий монстр
  - Кислотные атаки
  - Полет и бомбардировка
- **Slattern** (Категория 5) - босс из Бездны
  - Токсичные атаки
  - Призыв меньших Кайдзю

### ⚔️ Оружие
- **Chain Sword** - Цепной меч с_area_ атакой
- **Plasma Caster** - Плазменная пушка с поджиганием

### 🧠 Система Дрейфа (The Drift)
- Нейронная синхронизация пилотов
- Прогресс совместимости 0-100%
- Статусы: синхронизация, готовность, высокая совместимость
- Сохранение истории нейронных рукопожатий

### ✨ 8 Типов Микрочастиц
1. **Jaeger Exhaust** - выхлоп Егерей
2. **Plasma Trail** - плазменный след оружия
3. **Drift Connection** - связь Дрейфа между пилотами
4. **Kaiju Slime** - слизь Кайдзю
5. **Blue Blood** - синяя кровь Кайдзю
6. **EMP Wave** - ЭМИ волны
7. **Sword Sparks** - искры от цепного меча
8. **Plasma Explosion** - плазменные взрывы

### 📦 Блоки и Предметы
#### Ресурсы Кайдзю:
- Кость Кайдзю
- Орган Кайдзю
- Синяя кровь Кайдзю
- Амниотическая жидкость

#### Ресурсы Егерей:
- Ядро Егеря
- Сплав Кайдзю
- Чип нейронной связи

#### Технические блоки:
- Реактор Егеря
- Камера Дрейфа
- Стартовая площадка

## 🔧 Установка

### Требования
- Minecraft 1.21.x
- NeoForge 21.0.143-beta или выше
- Java 21

### Сборка
```bash
./gradlew build
```

### Запуск
1. Установите NeoForge для Minecraft 1.21
2. Поместите `.jar` файл мода в папку `mods`
3. Запустите игру
